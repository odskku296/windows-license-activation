## 激活步骤

拿到码之后，流程不复杂：

1. 点开始菜单，搜索并打开「设置」
2. 进入「系统 > 激活」
3. 点「激活 / 更改」按钮
4. 在弹窗里输入激活码，点「下一页」
5. 等待几分钟，提示激活成功即可

如果提示密钥无效，先回头核对系统版本名称里有没有“中文”二字，这是最常见的原因。确认版本没问题还是激活失败，联系客服处理，别急着重装系统。重装之前记得备份桌面和文档里的东西。

## 常见问题

**家庭版能升专业版吗？**
能。设置 > 系统 > 激活 > 更改产品密钥，输入专业版密钥，系统会自动升级，通常不需要重装。

**激活后会掉吗？**
正版授权正常使用不会无缘无故失效。但换主板、大改硬件这类操作之后的激活状态，官方页面没有给出明确说明，遇到这种情况先联系客服或微软支持确认。

**换电脑怎么办？**
这是全文最需要你自己确认的一点。商品页写“设备绑定，无法转移”，部分推广文章说绑定微软账号后可迁移，两者矛盾。有换机计划的人，下单前一定问清楚。

**一码能装几台？**
1 台。每单限购 2 件，两台设备就买两份。

**付了钱没收到码怎么办？**
先翻垃圾邮件，再去「荔枝商店 > 已购软件」页面查，两个地方都没有再联系客服。激活码会同时推到网页、短信和邮箱。

**需要发票能开吗？**
资料里没有说明发票类型和开票方式。需要报销的话，下单前直接问客服能不能开、开什么票，别等付完款再问。
